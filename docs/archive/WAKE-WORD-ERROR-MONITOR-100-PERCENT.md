## Automatic Fixes

Each error category has a dedicated fix strategy:

1. **Invalid AccessKey** → Updates from config and reinitializes
2. **Keyword File Not Found** → Falls back to built-in keywords
3. **Initialization Timeout** → Releases stuck manager and retries
4. **Frame Length Mismatch** → Logs and suggests processor fix
5. **Sample Rate Mismatch** → Logs and suggests resampling fix
6. **AudioWorklet Error** → Falls back to main-thread processing
7. **CORS Error** → Suggests using built-in keywords
8. **Network Error** → Retries after delay
9. **Porcupine Error** → Releases and reinitializes
10. **Keywords Array Error** → Fixes configuration and reinitializes
11. **Microphone Permission** → Provides user guidance
12. **AudioContext Error** → Reinitializes AudioContext and wake word
13. **Wake Word Manager Error** → Releases and reinitializes manager
14. **Sensitivity Error** → Validates and fixes sensitivity values
15. **MediaStream Error** → Reacquires media stream and reinitializes

## Usage

The monitor is automatically active when:
- Wake word is enabled (`wakeWordEnabled === true`)
- Picovoice AccessKey is configured
- At least one keyword path is provided

No manual setup required - it starts automatically and monitors all console errors in real-time.

## Debug Access

When debug mode is enabled (`?debug=1`):

```javascript
// View all detected errors
window.JARVIS_WAKE_WORD_ERROR_MONITOR.getErrorHistory()

// View all applied fixes
window.JARVIS_WAKE_WORD_ERROR_MONITOR.getFixHistory()

// Get comprehensive statistics
window.JARVIS_WAKE_WORD_ERROR_MONITOR.getStats()

// Clear history
window.JARVIS_WAKE_WORD_ERROR_MONITOR.clearHistory()
```
