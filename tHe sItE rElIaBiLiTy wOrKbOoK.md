# The Site Reliability Workbook

**Authors**: Betsy Beyer, Niall Richard Murphy, David K. Rensin, Kent Kawahara, Stephen Thorne  
**Publisher**: O'Reilly Media (2018)  
**Status**: Available via O'Reilly, libraries, or purchase

---

## Overview

A practical companion to the Site Reliability Engineering book, providing real-world case studies and concrete examples from organizations implementing SRE principles. Covers production security practices, monitoring and alerting for security events, incident response, and security in CI/CD pipelines.
