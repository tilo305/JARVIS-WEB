Draggable Chat Interface — Live Test

Use this checklist to verify the chat interface is draggable and working correctly.

1. Open the main app

Open JARVIS (new tab)

2. Manual verification checklist

Run through these checks in the main app:

  • Drag header: Click and hold the header (logo + JARVIS text area), then drag. The chat window should move.
  • Status click: Click the "Ready" status — it should reset (not start a drag).
  • Header buttons: Click Copy log or Export PDF — they should work (not start a drag).
  • Chat scroll: Scroll the chat messages area — scrolling should work on touch devices.
  • Position persist: Drag the window, refresh the page — it should restore to the last position.
  • Bounds: Drag near screen edges — the window should not go fully off-screen.

3. Automated tests

Run: npx jest debug/tests/draggable-chat-interface.test.js

All 13 tests should pass.
